🐍 Snake Game

A simple Snake Game built with Python and Tkinter. Control the snake, collect food, increase your score, and restart the game after Game Over.

🎮 Controls
Key	Action
W	Move Up
A	Move Left
S	Move Down
D	Move Right
Enter	Restart after Game Over
✨ Features

Classic Snake gameplay

W/A/S/D keyboard controls

Randomly generated food

Score tracking

Snake grows when food is collected

Wall and self-collision detection

Restart the game by pressing Enter

Simple graphical interface using Tkinter

🛠️ Requirements

Python 3.x

Tkinter

Tkinter is normally included with standard Python installations.

▶️ How to Run

Clone the repository:

git clone https://github.com/your-username/your-repository.git


Open the project folder:

cd your-repository


Run the game:

python snake_game.py
